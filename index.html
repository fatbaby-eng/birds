Phone recording tips
  • Hold the phone still; point the bottom mic toward the bird (not the screen).
  • Record at least 5–10 seconds while the bird is singing.
  • Step away from wind, traffic, and talking — background noise hides calls.
  • Watch the orange waveform: it should move when birds are loud. If it stays flat, move closer or check mic permission.

    Help — photos, field guide, export & backup

    Add photo — Attach a picture to any bird in the log (camera or gallery). It's shrunk to save space and stays on this device, riding along in JSON exports and the printable report.

    Portraits — When a bird is identified, the page asks iNaturalist for a small picture of the species so you can see who you're hearing. Only the species name is sent; pictures are remembered locally.

    Field guide — Pulls a short summary and portrait of the species from Wikipedia, plus a Song button. Only the species name is sent, and the answer is kept locally so it works offline next time.

    Bird Songs — Search any bird and play real recordings made by birders on iNaturalist (openly licensed, credited under each recording). Handy for learning a call before you go out.

    Download archive · JSON — Full backup for another phone or safekeeping. Re-import later with merge or replace.

    Download archive · Markdown — Readable journal for Notes, Obsidian, or any text app.

    Import · merge — Adds birds and notes from a JSON file without deleting what is already here. Duplicates are skipped.

    Import · replace — Wipes this device's log and loads the file. Use only when restoring a backup.

    Today's printable report — Print-friendly page for today (species summary, timeline, photos, notes).
